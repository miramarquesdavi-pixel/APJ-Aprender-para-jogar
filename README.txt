APRENDER PARA JOGAR
====================

Arquivos:
- index.html
- style.css
- script.js

Como abrir:
1. Extraia o ZIP.
2. Abra o arquivo index.html no navegador.
3. O site funciona sem servidor e guarda o XP no armazenamento local do navegador.

Observações:
- A estrutura visual foi feita sem depender de imagens externas.
- O código está preparado para você substituir/adicionar o background e outras imagens quando quiser.
- O projeto já possui matérias, trilhas, níveis, perguntas, XP e ranking.
- Para aumentar o conteúdo, edite a lista "subjects" e o objeto "questions" em script.js.
